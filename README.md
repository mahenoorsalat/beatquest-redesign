# BeatQuest Redesign

Cendo Sounds — BeatQuest Homepage Redesign

Project Goal

Redesign the Cendo Sounds homepage into a modern, premium, conversion-focused landing page for the BeatQuest SoundPax.

This is NOT meant to become a huge ecommerce website with lots of pages.

The homepage should function primarily as a focused music-product sales funnel:

Introduce BeatQuest immediately.

Give visitors access to the free BeatQuest Beta SoundPax in exchange for their email + phone number.

Encourage beta users to upgrade to the full BeatQuest SoundPax.

Clearly present the full product, audio previews, bonuses, social proof, and purchase CTA.

Keep the experience simple, modern, visually exciting, and optimized for conversion.

The design must work beautifully on both desktop and mobile.

IMPORTANT: Existing Website

The current Shopify website is:

https://www.cendosounds.com/

Please inspect this website carefully before designing.

Use the existing website as the source for:

Existing BeatQuest product information

Existing product images

Existing copy/content where useful

Existing branding elements

Existing product assets

Existing product structure

Existing visual assets that can be reused

Do NOT blindly copy the existing design.

The goal is to redesign and significantly improve the homepage, not replace the brand/product identity.

The current design was created by another developer, but the client does not like the current homepage enough and wants something more modern.

The client initially referenced:

https://producergrind.com/

But after reviewing additional inspiration, the preferred direction is closer to:

https://www.beatstars.com/

The client specifically likes the dark/black visual theme, strong sections, modern music-industry aesthetic, and rich visual hierarchy of BeatStars.

Use BeatStars as an important visual inspiration, but DO NOT clone it.

The final website should feel like an original premium music-production brand.

Homepage Structure

Keep the homepage relatively focused.

Do NOT create unnecessary sections just to make the page long.

Every section should have a clear purpose.

Recommended structure:

1. Navigation

Create a clean modern navigation.

Possible structure:

Cendo Sounds logo

BeatQuest

Sound Packs

About

FAQ

CTA button: "Get BeatQuest"

Keep navigation minimal.

On mobile:

Hamburger menu

Prominent CTA

Navigation should remain visually clean and should not compete with the hero.

2. Hero Section

This is the most important section.

The visitor should understand the product almost immediately.

Headline direction:

BEATQUEST

Create a strong headline/subheadline explaining what BeatQuest is.

Example concept:

"Your next beat starts here."

Supporting text should explain that BeatQuest is a premium sound pack containing drums, loops, bass, MIDI and other production-ready sounds.

Show a strong visual representation of the BeatQuest product.

Use existing product imagery from:

https://www.cendosounds.com/

where appropriate.

Hero should include:

Strong BeatQuest product visual

Short product description

Primary CTA

Secondary CTA for the free Beta Pack

Small trust/social-proof element if appropriate

Primary CTA:

GET THE FULL BEATQUEST

Secondary CTA:

GET THE FREE BETA PACK

The hero should immediately communicate:

What it is

Who it's for

Why it's useful

What the visitor should do next

Avoid a huge amount of text.

3. Free Beta SoundPax Section

Create a visually distinct section promoting the free Beta SoundPax.

Purpose:

Capture leads.

The user can get the free Beta SoundPax after submitting:

Email

Phone number

Messaging should make this feel like a valuable free product, not a boring newsletter signup.

Possible direction:

TRY BEATQUEST FOR FREE

"Get the BeatQuest Beta SoundPax and start creating before you commit."

Show:

Beta pack artwork

Short description

What's included

Email field

Phone field

CTA

CTA:

GET THE FREE PACK

After submission, the user should conceptually be taken to a download/confirmation state.

For the prototype, implement the UI flow realistically.

4. Upgrade / Conversion Section

Immediately after the free Beta Pack, introduce the upgrade.

Concept:

Liked the Beta? Go Full BeatQuest.

Explain that the full BeatQuest package contains the complete sound pack plus five bonus sound packs.

Make the value proposition extremely clear.

Use visual comparison if useful:

FREE BETA
vs.
FULL BEATQUEST

The full version should feel like an obvious upgrade.

CTA:

GET FULL BEATQUEST

5. Full BeatQuest Product Section

This is the core of the website.

Make this section visually impressive.

Show the main BeatQuest product artwork prominently.

Include:

Product name

Short description

Price

What's included

Number of sounds/content if available from the current website

Product format/file types if available

CTA

Product imagery

The customer should be able to understand the value without reading a wall of text.

Use premium product cards / visual composition.

Do not invent product specifications.

If exact information is available on the existing Cendo Sounds site, use it.

6. Audio Preview Experience

This is extremely important.

Do NOT use a boring default browser audio player.

Create a modern audio-preview interface inspired by premium music/sample websites.

Use waveform-style visuals.

Each sample should have:

Play button

Waveform

Track/sample name

Category

Duration

Progress state

Hover/active state

Possible categories:

Drums

Loops

Bass

MIDI

One Shots

Other categories found on the existing website

Use realistic waveform visuals.

The interface should feel like a professional music-production platform.

Make the audio section visually rich but clean.

If actual audio files are accessible from the existing website, structure the implementation so they can be connected.

Do not invent fake audio URLs.

For the prototype, sample audio UI can be represented with realistic placeholder interaction if actual files cannot be accessed.

7. What's Inside BeatQuest

Create a strong visual breakdown of the main pack.

For example:

Drum Loops

One Shots

Bass

MIDI

Loops

Other included content

Only use categories/details that can be verified from the current Cendo Sounds website.

Present these as visually interesting cards rather than a boring bullet list.

Each card could include:

Icon or abstract graphic

Category name

Short explanation

Number of sounds where available

8. Five Bonus Sound Packs

This is another major selling point.

Show the five bonus sound packs included with the full BeatQuest package.

Each bonus pack should have:

Artwork

Name

Short description

Individual value/price if available

"Included with BeatQuest" indicator

Make it visually obvious that purchasing BeatQuest gives access to all five bonuses.

Possible headline:

5 BONUS SOUND PACKS INCLUDED

Supporting message:

"More sounds. More inspiration. More ways to build your next record."

Important:

The five bonus packs can also be sold individually.

Therefore, structure the UI so each bonus product could later link to its own Shopify product page.

Use existing product information and imagery from Cendo Sounds wherever possible.

Do not fabricate product names or pricing.

9. Value / Offer Section

Create a strong conversion section that communicates the total value.

Example visual concept:

BeatQuest
+
Bonus Pack 01
+
Bonus Pack 02
+
Bonus Pack 03
+
Bonus Pack 04
+
Bonus Pack 05

Then show the current offer/price.

Make the offer feel valuable without using aggressive spammy ecommerce design.

Use a strong CTA.

10. Social Proof / Testimonials

Create a social proof section.

If testimonials/reviews are available on the current website, reuse them.

Otherwise create a clearly marked prototype structure rather than inventing fake customer claims.

Possible content:

Customer testimonials

Producer quotes

Number of producers/users if verified

Logos/social proof if available

Keep it authentic.

11. Why BeatQuest

A short section explaining why someone should use BeatQuest instead of random sample packs.

Potential themes:

Production-ready sounds

Fast workflow

High-quality samples

Creative inspiration

Designed for modern producers

Do not over-explain.

Use 3–4 strong visual points.

12. Final CTA

End with a strong conversion section.

Large visual treatment.

Example direction:

READY TO BUILD YOUR NEXT BEAT?

"Get BeatQuest and start creating."

Buttons:

GET BEATQUEST

and optionally:

TRY THE FREE BETA

This should feel like a strong final conclusion rather than another generic section.

13. Footer

Minimal footer.

Include relevant links such as:

BeatQuest

Sound Packs

About

Contact

FAQ

Privacy

Terms

Social links

Use information from the existing site where available.

Mobile Design

This is VERY important.

The homepage must be designed intentionally for mobile, not simply shrunk from desktop.

Optimize:

Navigation

Hero artwork

CTA buttons

Product cards

Audio players

Waveforms

Bonus-pack cards

Forms

Typography

Spacing

Touch targets

On mobile:

Keep CTA buttons easy to tap.

Stack product information intelligently.

Make audio players usable with one hand.

Avoid overly wide horizontal layouts.

Keep important information above the fold.

Preserve the premium dark visual aesthetic.

The mobile experience should feel like a premium music app
